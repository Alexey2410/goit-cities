# Гра в міста.
Знайома гра з дитинства.
## Хід гри
По черзі користувач та комп'ютер вводять назву міст. Користувач у поле вводу. Вони приймаються лише в разі наявності їх у базі та їхнього не використання.
## Кінець гри
Гравець пише у полі вводу слово "здаюсь". Комп'ютер коли закінчуються доступні міста.
На фінальному вікні буде рахунок ходів.
## Запуск програми
Для запуску програми за замовчуванням використовується файл з поточної директорії cities_ukraine.json зі списком доступних міст в форматі json.
Кожне місто представяє окремий об'єкт з полем "name".
При бажанні, в параметрах запуску можна передати шлях до файла зі списком доступних для гри міст.
